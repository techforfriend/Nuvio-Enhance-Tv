# Nuvio KE brand files

The Nuvio KE mark is Nuvio's N with a KE edition chip in its corner, and the lockup reads "Nuvio KE" with K and E folded
from the N's ribbons. The N is NuvioMedia's Nuvio logo, redrawn as vector art for this fork.

| File | Use |
|---|---|
| `ke-mark.svg`, `ke-mark-{1024,512,256}.png` | The mark on a transparent background. The ring around the chip is see-through. |
| `ke-icon.svg`, `ke-icon-{1024,300}.png` | The mark on the graphite tile (#111113): avatars and the subreddit icon (300 px). |
| `ke-lockup.svg`, `ke-lockup-2400.png` | Mark and wordmark, for dark backgrounds. |
| `geometry.json` | Every path and gradient the files above are built from. |

The files are generated, so edit the generator, not these files. Keep the mark on dark backgrounds, and don't recolour,
stretch or crop it. The play point on the E's middle bar always shows in full.
